Добрый день!

Программа позволяет добавлять любое количество архивов, и в каждом из них, независимо друг от друга,
создавать любое количество заметок. Насколько я понял требования, все критерии выполнены.

Main - создание архива, классов и движение по меню
archives/noted - классы для создания архива и заметок
menu - создание и движение по меню, чтобы не дублировать код
